# Audio Volume Limiter (Chrome Extension, Manifest V3)

## ติดตั้งเพื่อทดสอบ
1. เปิด `chrome://extensions` แล้วเปิด Developer mode
2. กด Load unpacked แล้วเลือกโฟลเดอร์นี้
3. เปิดแท็บที่มีเสียง (เช่น YouTube) กดไอคอนส่วนขยาย แล้วเปิดสวิตช์

## Checkpoint การทดสอบ
1. **MVP**: เปิดสวิตช์แล้วเสียงต้องไม่ดับ
2. **Limiter**: เล่นคลิปที่ดังกระทันหัน มิเตอร์ต้องไม่เกินเส้นสีเหลืองมากนัก (ดูหมายเหตุด้านล่าง)
3. **Memory**: สลับเปิด/ปิดหลายรอบ แล้วดู `Shift+Esc` (Chrome Task Manager) ต้องไม่มีโปรเซสค้างหรือหน่วยความจำเพิ่มขึ้นเรื่อย ๆ
4. **Compatibility**: YouTube, Twitch, Netflix, Disney+, Spotify, Web Radio

## ตัวควบคุมเสียง
- **เพดานเสียงสูงสุด** (-60 ถึง 0 dB): เสียงส่วนที่ดังเกินค่านี้จะถูกบีบ ยิ่งตั้งต่ำ ยิ่งเงียบลงมาก
- **ระดับเสียงรวม** (-40 ถึง 0 dB): ลดทุกอย่างลงเท่า ๆ กัน (ที่ -40 = ปิดเสียง) ใช้ร่วมกับเพดานเสียงได้

## หมายเหตุด้านเทคนิค
- Chrome ใส่ makeup gain ให้ DynamicsCompressorNode อัตโนมัติ ระดับเอาต์พุตจริงจึงอาจต่างจากค่า threshold เล็กน้อย ให้ดูมิเตอร์ประกอบและปรับที่ `makeupDb` ใน `PRESETS` (background.js) ถ้าต้องการ
- Compressor ทั่วไปไม่ใช่ brick-wall limiter สมบูรณ์ ทรานเซียนต์สั้นมากอาจเล็ดลอดได้เล็กน้อย
- รีเฟรชหรือเปลี่ยนหน้าในแท็บที่คุมอยู่ จะหยุดคุมเสียงและคืนทรัพยากร (สิทธิ์ activeTab หมดไปพร้อมการโหลดหน้าใหม่) ต้องกดเปิดใหม่
- คุมได้ครั้งละหนึ่งแท็บ การเปิดในแท็บอื่นจะย้ายการคุมมาแท็บนั้น
